# Laundry Website Project Plan

## 1. Overview
Build a modern, clean, and user-friendly laundry website. The design will focus on "freshness" and "cleanliness" using a palette of cyans, blues, and whites.

## 2. Features
- **Hero Section**: High-impact introduction with CTA (Book Now).
- **Services**: Wash & Fold, Dry Cleaning, Ironing, Bulk Laundry.
- **Pricing**: Clear pricing tiers/tables.
- **Booking Flow**: Step-by-step booking form (Service -> Schedule -> Details).
- **Process/How It Works**: Steps (Schedule, Pickup, Clean, Deliver).
- **Testimonials**: Social proof.
- **FAQ**: Common questions.
- **Contact**: Simple contact form and location info.
- **Responsive Navigation**: Sticky header with mobile menu.

## 3. Tech Stack
- React 19 + Vite
- Tailwind CSS
- Lucide React (Icons)
- Framer Motion (Animations)
- Sonner (Notifications)
- Shadcn UI (Components)

## 4. Components & Pages
- `App.tsx`: Main entry with routing/layout.
- `components/Header.tsx`: Responsive navigation.
- `components/Hero.tsx`: Hero section.
- `components/Services.tsx`: Service cards.
- `components/HowItWorks.tsx`: Process steps.
- `components/Pricing.tsx`: Pricing cards.
- `components/BookingForm.tsx`: Multi-step form.
- `components/Testimonials.tsx`: Customer reviews.
- `components/Footer.tsx`: Information and links.

## 5. Visual Theme
- Primary: Cyan-600 (#0891B2)
- Secondary: Emerald-600 (#059669)
- Background: Slate-50 (#F8FAFC)
- Typography: Inter (Sans-serif)
- Accents: Blue-600 (#2563EB)
